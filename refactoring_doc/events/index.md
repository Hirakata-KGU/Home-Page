# 企画一覧ページ (`app/pages/events/index.vue`) 要約 & リファクタリング指針

本ドキュメントは、全企画一覧画面（`/events`）の実装仕様、設計思想、および今後のリファクタリングポイントをまとめたものです。

---

## 1. ページ概要 & 主な機能

- **目的:** 模擬店・グルメ、文化館展示、音楽館・ステージ、芸能企画の全59企画を横断的に一覧表示・検索可能にする。
- **データソース:**
  - `modules/festival-data.ts` が Excel から自動生成した 4 つの JSON を `app/data/events.ts` で統合した `allEvents` を参照。
- **主な機能:**
  1. **メインカテゴリ切替:** 全て / 模擬店・グルメ / 文化系・展示 / 音楽館・ステージ / 芸能ステージ
  2. **開催日フィルター:** 全て / 10月31日（Day 1） / 11月1日（Day 2）
  3. **フリーワード検索:** 企画名、団体名、紹介文、会場名、メニュー・展示内容をインクリメンタル検索（デバウンス処理付き）
  4. **URLクエリ同期:** 検索条件（`category`, `day`, `q`）をブラウザ履歴・URLクエリに双方向同期（ブックマークや戻る/進む操作に対応）
  ※ 以前存在していた「ジャンル / 形態（サブカテゴリ絞り込み）」は、UIの煩雑化を防ぎ直感的な検索体験にするため要望に基づき撤廃。

---

## 2. 実装されたコア設計 & UI/UX

### 2.1 URLクエリの双方向同期 (`syncUrlQuery`)
- クエリパラメータの変更を監視し、ブラウザのリロード時にも検索・絞り込み状態を完全復元。
- 文字入力時は 300ms のデバウンスを挟み、ブラウザ履歴の過剰なプッシュを防止（`router.replace` 使用）。
- `isSyncingFromRoute` フラグにより、ルート監視と入力監視の無限ループを抑制。

### 2.2 モバイルフレンドリーなカードグリッド
- スマートフォン幅でも情報が整理されて見えるよう、バッジ（カテゴリ、日程、場所）、サムネイル画像、タイトル、団体名、説明文、詳細矢印をコンパクトに配置。
- 検索結果が 0 件の場合の丁寧な空ステート案内（検索リセットボタン付き）。

## 3. リファクタリング時の留意点

1. **Composable への分離 (`useEventFilters`):**
   現在 `events/index.vue` 内に書かれている「URLクエリ同期」「正規化ヘルパー」「フィルタリング計算ロジック」を `composables/useEventFilters.ts` に抽出することで、スクリプトの可読性を大幅に向上可能。
2. **コンポーネントの分割:**
   - `components/events/EventFilterBar.vue`: カテゴリ・日程タブ・検索バー
   - `components/events/EventCard.vue`: 企画カード単体（アクセシビリティ対応）
   - `components/events/EventEmptyState.vue`: 検索結果ゼロ時の表示
3. **画像の最適化:**
   サムネイル表示において `NuxtImg` の `sizes` や `format="webp"` を適切に指定し、LCP (Largest Contentful Paint) を向上させる。
