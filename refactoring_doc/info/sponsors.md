- 平潟祭 2026 にご協賛いただいた企業・団体への感謝を示し、来場者に紹介する。

## 4. データ設計 (`app/data/sponsors.ts`)

```ts
export interface Sponsor {
  id: string        // 識別子（key 用）
  name: string      // 表示名
  logo?: string     // 将来用: /images/sponsors/xxx.png
  url?: string      // 将来用: 公式サイト（あれば外部リンク化）
}

export const sponsors: Sponsor[] = [ /* 12社 */ ]
```

- `logo` / `url` は将来用の任意項目（現状は全社未設定）。設定された場合のみ画像表示・リンク化（`target="_blank" rel="noopener noreferrer"`）。
- 企業追加・順序変更はこのファイルのみで完結させ、ページ側の改修を不要にする。

## 5. ページ設計 (`app/pages/info/sponsors.vue`)

### 構成
1. **ページヘッダー**: 既存 `PageHeader` / `SectionTitle` を使用し、タイトル「ご協賛一覧」。
2. **謝辞文**: 「平潟祭 2026 は、以下の企業・団体の皆様のご協賛により開催されます。心より感謝申し上げます。」程度の短文（創作ポエムは入れない。about.md の方針を踏襲）。
3. **企業一覧グリッド**: 社名カードを並べる。
4. **お問い合わせ導線（実装する）**: ページ下部に「協賛に関するお問い合わせはこちら」と、お問い合わせページ (`/info/contact`) へのボタンリンクを設置（既存 `btn-pill` 等のスタイルを流用）。

### レイアウト
- スマホ: 1列 / `sm`: 2列 / `lg`: 3列（`grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`）。
- 各カードは白背景・角丸・細いボーダー（サイトのスプラウトグリーン系 `sprout-border` を踏襲）。社名は中央揃え、長い社名（例: サントリービバレッジソリューション株式会社）が折り返しても崩れないよう `min-h` と `break-words` を指定。
- ロゴは提供されないため、ロゴ枠は実装しない（社名テキストのみ）。
- 全社同格の扱い（ランク分けなし）。順序は提供資料どおり。

### スタイル・実装方針
- Tailwind ユーティリティ中心。繰り返し要素のカードは `v-for` で生成し、長くなるクラスのみ `<style scoped>` に `.sponsor-card` として切り出す。
- アクセシビリティ: 一覧は `<ul>/<li>`、見出し階層を維持。

### SEO / メタ
```ts
useSeoMeta({
  title: 'ご協賛一覧｜平潟祭 2026',
  ogTitle: 'ご協賛一覧｜平潟祭 2026',
  description: '平潟祭2026にご協賛いただいている企業・団体の皆様をご紹介します。',
  ogDescription: '平潟祭2026にご協賛いただいている企業・団体の皆様をご紹介します。',
```

## 9. デザイン改善（UIブラッシュアップ）

- **課題:** 白い独立カードが12個並ぶことで無機質・圧迫感（気持ち悪い印象）を与えていた。
- **対応:**
  - 独立した白い小箱グリッドを撤廃し、1枚の格調高い「芳名板（サインプレート）」フレームに統合。
  - 各社名を淡い若葉色のプレート＋左側の新芽サークルバッジで上品に整列。
  - 背景に新芽の透かし、見出し下に UiOrnamentLine を配し、大学学園祭らしい感謝と品格のある佇まいにリニューアル。
